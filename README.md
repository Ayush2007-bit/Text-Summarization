# AI Text Summarization App

An AI-powered web application that summarizes long text and dialogues using a fine-tuned T5 Transformer model.

The application is built using FastAPI and provides a simple web interface for entering text and generating concise summaries.

## 🚀 Features

- AI-based text summarization
- Uses T5 Transformer model
- FastAPI backend
- Simple HTML web interface
- Supports long text/dialogues
- CPU and CUDA support
- REST API endpoint for summarization
- Clean and easy-to-use interface

## 🛠️ Technologies Used

- Python
- FastAPI
- Transformers
- PyTorch
- T5 Transformer
- Jinja2
- HTML/CSS
- Uvicorn
